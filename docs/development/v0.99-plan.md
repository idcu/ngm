# v0.99 计划 — **承诺账本：把"两边必须一致"逐条记账**

> 来源：[v0.98 复盘](./v0.98-retrospective.md) §5 候选 1/2。
>
> v0.98 留下的一句话：**"逐字镜像"是一句承诺，而承诺不会自己检查自己。**
> 这一版把这句话本身做成一条可执行的东西。

---

## 1. 先清点（不猜）

用六个词扫 Go 非测试源码 + `scripts/*.sh|*.mjs`：

| 词 | Go | scripts |
|----|----|---------|
| `逐字镜像` | 0 | 1 |
| `逐字对齐` | 0 | 2 |
| `必须一致` | 3 | 2 |
| `必须保持` | 1 | 0 |
| `两份实现` / `两条实现` | 2 | 2 |
| **合计（去重后）** | **6** | **8** | 

⇒ 14 处。规模适合逐条分类，不适合"有空再说"。

## 2. 分类规则

| 档 | 判据 |
|----|------|
| 已被机械对账 | 写明**判据名**；判据名必须真实存在（v0.53 的老教训：登记不能看着空气） |
| 验不了 | 写明**为什么**（缺环境 / 是说明文字 / 已合并为单实现） |
| 两者都不是 | **这就是本版要补的洞** |

## 3. 三处需要补的洞（先看洞，再写网）

| 洞 | 情况 | 处置 |
|----|------|------|
| `internal/adapter/wasm.go` 的 `entryArgs` | 注释说"与 subprocess 侧必须一致"，而 `buildInvocation` 已经前置过 `entry.Args` ⇒ **wasm 形态传两遍**（现有测试比的是两个 builder 的输出——比错层级） | 删掉第二处（只剩一处 = 无需一致）；判据分行为层 + 结构层 |
| `internal/sbom/spdx.go` 的"两种格式的依赖图形必须一致" | 现有测试各自检查两种格式，**没有**一条把两侧的边放在一起比 | 新增对账网（归一化后逐条相等；图不完整时两侧都整段省略） |
| `internal/mappings/validate.go` 的"由 CLI 的集成测试保证" | 常量未导出 ⇒ **没有任何包能同时看见两个名字**，那句话做不到 | 导出 `LockFileName` + 在能同时 import 的目录里比 |
| `internal/resolve/normalize.go` 的"新增 host 时必须同步 `hostSlugs`" | 两张表互为逆映射，**零判据**（搜遍 `internal/resolve` 的测试） | 新增对偶网（两表互逆 + 公开 API 往返 + 未知 host 原样保留） |

## 4. 计划

| # | 项 | 验收 |
|---|----|------|
| 1 | `entry.Args` 只前置一次 + 结构层守卫（登记允许出现的每一行） | 牙齿：放回旧代码 ⇒ 结构层红、**行为层仍绿**（这正是它当初活着的原因） |
| 2 | 两种 SBOM 格式图形对账 | 4 条边的夹具；图不完整 ⇒ 两侧都空 |
| 3 | `LockFileName` 导出 + 对账 | 两个常量相等 + 常量真被用 |
| 4 | `slugHosts` / `hostSlugs` 对偶 | 两表互逆 + 往返 + 未知 host 保留 |
| 5 | **承诺账本**（14 处逐条登记，两个方向对账） | 牙齿三条：未登记 ⇒ 红 · 措辞变了 ⇒ 红 · 判据名不存在 ⇒ 红 |

## 5. 不做

- 不推 tag / jsonkit（只为发布与镜像覆盖）；
- 不把账本扩到**全部**注释（六词是显式选择的**筛子**，口径写进判据）；
- 不给 `.ps1` 文件头那 11 处"唯一实现"建新网——它们守的约定已由 v0.90 的参数对齐网与实跑网覆盖。
