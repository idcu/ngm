# v0.19 复盘 — 用户看到的文本也是接口

> 体例同各版：逐组验收 → 未达成项 → 设计偏离 → 缺陷清单 → 过程洞察 → 指标 → 下一版候选。
>
> 范围来源：[v0.18 复盘](./v0.18-retrospective.md) §7 候选 1（联网复核）。
> 本版不是复核本身，而是**复核时顺手抓到的那条**：
> `config validate` 在**没有 `ngm.json`** 的目录里照样打印 **`ngm.json OK`**。
>
> 一句话结论：**退出码与措辞，是脚本与人分别读到的那一份契约。**

---

## 1. 逐组验收

### 1.1 A 组 — 用法文本写出自己的退出码

新增 8 段（`init` / `add` / `update` / `remove` / `mappings` / `cache` / `store` / `config`），
并**修正 `install` 不完整的一段**：它写着 `0/3/4`，而实测还能退 **2**（postinstall 钩子失败或超时、落地字节校验不过）与 **5**（需要 Deno 而缺失或不可用）。

配套机械网：`TestV19EveryCommandDocumentsItsExitCodes` — 现在对 **21 个命令**全部断言
（v0.19 之前是 13/21）。它是**一次性覆盖**：以后再加命令，缺段就会立刻红。

### 1.2 B 组 — `ngm config` 的三处缺陷

| # | 缺陷 | 处置 |
|---|------|------|
| ① | `--dir` 不存在：只认进程 CWD | 加上 `--dir`（默认 `.`，与其余命令一致） |
| ② | 多余位置参数被静默丢弃 | 改为 `NArg() != 1` → 打印用法 + exit 3 |
| ③ | 没有 `ngm.json` 时照样打印 `ngm.json OK` | 改为 exit 3 并点名目录 |

配套的机械网 `TestV19ConfigValidatesTheDirectoryItIsToldTo` 断言这三条，
外加一条**对照**：`config show` 是查看，不设门禁。

### 1.3 C 组 — 内部阶段标签（`M\d`）

`M0…M7` 只在项目内部有意义，此前泄漏到**两处**用户可见的字符串（`add` 的提示、`update` 的 NOTES）。
配扫描网 `TestV19NoInternalStageLabelsInUserFacingText`（`go/scanner`，只看字符串字面量）。

| 位置 | 之前 | 现在 |
|---|---|---|
| `cmd/ngm/add.go:137` | `next: run \`ngm install\` to resolve and lock (M3)` | 去掉 `(M3)` |
| `cmd/ngm/update.go:34-35` | `M1 阶段…；ngm.lock 的写入属于 M3`（**且是错的**） | 改写为今天的实际行为 |

### 1.4 D 组 — 引擎默认：从"待决"变成"决定"（[ADR-025](../adr/adr-025-no-builtin-engine-defaults.md)）

决定：**不设内置默认**。一句话理由：默认一旦由"机器上装了什么"决定，
就会**在没有人改任何文件的情况下改变行为**——这与 ADR-018 拒掉可达性删除是同一个形状。

## 3. 设计偏离登记

| # | 计划写的 | 实际做的 | 为什么 |
|---|---------|---------|-------|
| 1 | D 组：解决"要不要内置默认引擎" | 写成 ADR 并**不改行为** | **"挂着的待决项"本身就是缺陷**：没决定 = 没人负责。写成带重开条件的决定，等于把它从"没人管"变成"有据可依" |
| 2 | B 组只打算修措辞 | 结果补了一个**新增能力**（`--dir`） | "测试只能靠 `chdir` 绕过"不是措辞问题，是**能力缺失的信号** |
| 3 | C 组的网扫全仓库 | 只扫**非测试**文件的**字符串字面量**（`go/scanner`） | **判据取窄是刻意的**：注释里合法出现 `M\d`，但若把禁区扩到注释就会误报——**会误报的门禁会被忽略** |
| 4 | 统一 JSON 形状（v0.16 记过） | 不动 | 破坏性变更，要另立决定；本版只补"退出码与措辞" |

## 5. 过程洞察

### 5.1 待决项不决定，本身就是缺陷

"引擎要不要内置默认"挂了两版，每版复盘都写"待决"。**写"待决"不等于处理了它**：
它还在那里，而且没人负责。本版把它写成 ADR——意义不在"解决了"，而在**它现在是一个
有据可依的结论，而不是一个没人管的问题**。

### 5.2 绕过去的那一刻，就该补上

`config` 缺 `--dir`，于是测试只能 `chdir`；v0.15 的探针也照绕。
一整条绕过链就此悄悄成立，直到有人**不绕**（联网复核）才发现：
**绕过去的动作本身就是问题**。

### 5.3 内部标签泄漏 = 两个世界没隔开

`M\d` 是内部里程碑编号，却出现在打印给用户看的字符串里。
**同一份东西不该有第二个读者理解不了的记号。**

### 5.4 过时比缺失更危险

`update` 那句"lock 写入属于 M3"不仅过时，而且**错**。
缺失只是没说，过时是**说错了一条事实**——读它的人会据此做出错误判断。

### 5.5 先测量，再决定要不要动手（第三次）

v0.18 的复核本不打算找缺陷，只想量一条路径，结果测量本身成了发现。
本版动手前也先量了：`2` 与 `5` 都有代码路径与既有测试支撑。
**没有测量就动手，就是把想象写成契约**——这条纪律在本项目已第三次起作用。
