# v0.99 复盘 — **承诺账本：一句"必须一致"值两处洞**

> 计划：[v0.99 计划](./v0.99-plan.md)
>
> 一句话结论：v0.98 说"**"逐字镜像"是一句承诺，而承诺不会自己检查自己**"。
> 这一版把仓库里那 14 处同类承诺逐条记账——**当场读出两处真洞**。

---

## 1. 清点：14 处

六个词（`逐字镜像` · `逐字对齐` · `必须一致` · `必须保持` · `两份实现` · `两条实现`）扫
Go 非测试源码 + `scripts/*.sh|*.mjs` ⇒ **14 处**。逐条分类后：

| 档 | 数量 | 处置 |
|----|------|------|
| 已被机械对账 | 6 | 写上判据名（含跨包的） |
| 验不了（有理由） | 5 | 写明为什么（说明文字 / 已合并为单实现 / 输入在 CI） |
| **没人守** | **3 + 1** | 本版补网 |

## 2. 两处真洞（读出来的，不是猜的）

### 2.1 `entry.Args` 被前置了两遍（注释正说着"两者必须一致"）

`wasmEngine.entryArgs` 做了一次前置，而它调用的 `buildInvocation` **已经前置过**
⇒ 同一个引擎在 wasm 形态下把清单里的固定参数传**两遍**，subprocess 形态传一遍。

**它为什么一直没被发现**——三条原因叠在一起：

| 原因 | 说明 |
|------|------|
| 现有测试比在**错误的层级** | `wasm_test.go` 比的是 `buildInvocation(wasm, req)` 与 `buildInvocation(sub, req)`——前置发生在它**之后** |
| 今天**不可达** | `Args` 由 `command` 派生，而 wasm 条目的 `command` 是模块路径 ⇒ 通常为空 |
| 注释**看起来**在守它 | 那句话本身写得没错，只是没人执行它 |

**修法不是"两处各修对"，而是让它只剩一处**（v0.82 的老办法）：wasm 侧直接用 `inv.Args`。

判据分两层，而牙齿证明了这个分层**不是装饰**：

| 层 | 内容 | 牙齿（放回旧代码） |
|----|------|-------------------|
| 行为层 | 带 `Args` 的条目走 `buildInvocation` 后前缀恰好一次 | **仍然绿**——它观测不到"第二次" |
| 结构层 | `internal/adapter` 里 `entry.Args` 只允许出现在登记过的行；两个 `--version` 探针必须逐字相同 | **红**并点名那一行 |

> 行为层看不到、结构层能看到——这正是这个 bug 能活到今天的原因。
> 顺带：`annotate(err, e.entry, inv.Args)` 现在报的就是**真正跑的那份 argv**。

### 2.2 "由 CLI 的集成测试保证"是一句做不到的承诺

`mappings/validate.go` 里，`lockFileName` 的注释写着"两者口径一致由 CLI 的集成测试保证"。
而常量的可见性决定了：**没有任何包能同时看见它和 `lock.FileName`**（mappings 刻意不依赖 lock）
⇒ 那句保证永远无法被任何测试执行。处置：导出 `LockFileName`（依赖方向不变），
在能同时 import 两个包的目录里把两个名字放进同一条判据。

## 3. 另外两处补网（不是洞，是"没有网"）

| 承诺 | 原文 | 新网 |
|------|------|------|
| 两种 SBOM 格式的依赖图形必须一致 | `spdx.go`："否则『挑一个格式看』的人会得到两棵树" | 同一批条目导出两种格式，边归一成 `父名 → 子名` 后逐条相等；图不完整 ⇒ **两侧都整段省略**（v0.81 纪律），组件数不受影响 |
| `slugHosts` 与 `hostSlugs` 必须同步 | `normalize.go`："新增 host 时必须同步 hostSlugs" | 两表互为逆映射 + 公开 API 往返（`ParseSlug` → `Slug()`）+ 未知 host **原样保留**；零判据（搜遍 `internal/resolve` 的测试） |

## 4. 承诺账本（本版的主交付）

`TestV99MirroringClaimsAreAccounted`：六词命中 ⇒ 每一处必须被 `claimsLedger` 里一条登记项认领。

| 方向 | 触发 |
|------|------|
| 未登记的承诺 | 新加一句"必须一致"的注释 ⇒ 红并点名 `file:line` |
| 登记看着空气 | 把登记的措辞改掉 ⇒ 红（**改措辞就是要重看一遍**，这是设计意图） |
| 判据名不存在 | 登记指向 `TestV99NoSuchNet` ⇒ 红 |

账本口径（写在判据里）：六词词表是**显式数据**；扫描范围排除 `.ps1`（按约定只转调，那份约定由 v0.90 守着）与文档；**它是筛子不是证明**——挡住"从没被登记过"这一档，"登记的判据真的管用"由那些判据自己的牙齿负责。

**一处记账边界**（写出来，不留给猜）：登记表收 `cmd/ngm` 的判据（机制如此），
而本版的 `TestV99EntryArgsArePrependedExactlyOnce`（`internal/adapter`）与
`TestV99HostMapsAreInverse`（`internal/resolve`）在各自包里 ⇒ **没有进登记表**，
但**被承诺账本点名**（账本查找判据名时扫全仓库的 `_test.go`）。两条路各管一半，不重叠也不留空。
