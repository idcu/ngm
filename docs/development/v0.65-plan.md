# v0.65 计划 — **矩阵的每一列都要有自己的证据**

> 范围来源：v0.64 复盘候选 1（v0.56 普查留到现在的那条："V37 的 8 个形状列表 / V39 的 2 个维度列表只有计数下限，新增形状/维度不强制"）。
>
> 一句话目标：把"**新增一列**"从"覆盖数字变大"变成"**必须真的测到东西**"。

---

## 0. 起点：两处只有**全局**下限

| 网 | 现状 |
|----|------|
| V37（21 命令 × 8 配置错误形状） | 只有全局 `error-text ≥ 40` —— 它回答"矩阵整体还在动吗"，回答不了"**这一列**还在动吗" ✗ |
| V39（21 命令 × 2 参数维度） | 只有 `runs ≥ N` ＋ 退出 0 的双向登记（后者已经是好守卫 ✓）；两个维度写作循环里的**字面量** ✗ |

## 1. 处置

1. **V37**：把 8 个形状提成命名的轴 `configErrorShapes` ✓，并给每一列加两道证据断言：
   - ① 这一列至少有一格**走到配置层**；
   - ② 这一列的签名（每格的"通道 + 整份归一化输出"）**不能与另一列完全相同** —— 等价只能在 `shapeEquivalents` 里**具名**说明。
2. **V39**：把 `[]string{"no-args","junk-arg"}` 提成 `argumentDimensions` ✓，每个维度自带一句**契约**（`wants`），并有计数下限守卫。
3. 两处**夹具**按新证据修（V37 实测发现两列等价 ⇒ 它们是**夹具缺字段**）。

## 2. 验收

```bash
go test -count=1 -run 'TestV37|TestV39|TestV53' -v ./cmd/ngm
go test -count=1 ./...          # 整套，不手挑
gofmt -l . && go vet ./... && bash scripts/check-docs-links.sh
```

**牙齿**：把某一列的夹具换成合法项目 ⇒ 红（exit-0 登记那条先响）· 两列逐格相同 ⇒ 红（**本次真的抓到了**）。
