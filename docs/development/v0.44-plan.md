# v0.44 计划 — 补上 v0.35 记下的**"可达性未证明"**

> 范围来源：v0.37 ~ v0.43 每版候选里都挂着的第 5 条（原话出自 [v0.35 复盘](./v0.35-retrospective.md) §3.1）。
>
> 一句话目标：`verify.go` 那一支（`errCommitMissing` + `opts.Offline`）**从没被任何用例走到过**——
> 也就是说，v0.35 修掉的那个"死赋值"里写下的建议，**没有任何证据表明它到得了用户眼前**。
> 这一版把它造出来。

---

## 0. 触发条件（从代码读出来，不是猜的）

| # | 条件 | 出处 |
|---|------|------|
| ① | ref 检查**不是**操作性失败（**漂移也算**） | `verify.go`：`if refCheck.Operational { … } else { checkDigest … }` |
| ② | lock 的 commit **不在**本机 mirror 里 | `checkDigest` → `errCommitMissing` |
| ③ | `--offline` | `switch { case opts.Offline: … }` |

> ① 是关键：它让构造不必依赖"一个 ref 指向缺失对象的畸形镜像"——
> 只要**锁钉了一个本机没有的 commit**就够了。

## 1. 构造（用**真实存在**的 commit，不用假 SHA）

1. `seedDep` 得到合法世界（锁钉 A，mirror 有 A）；
2. **上游再提交一个** B——它真实存在，但本机 mirror 里没有（install 已经取过了）；
3. 把锁里的 commit 改写成 B；
4. `ngm verify --offline`。

假 SHA 也能触发同样的分支，但它会让语义变脏（同时牵扯"上游丢弃了该提交"）；
用 B 之后这条路径的语义是干净的：**我离线，而 mirror 落后**。

## 2. 要钉住的三件事

| # | 钉住什么 |
|---|---------|
| 1 | 这条分支**真的到得了**（exit 4 + 报告 + `→` 行） |
| 2 | 它给出的建议**承认自己的成因**（"the local mirror is cold"），且与另外两种成因**不同** |
| 3 | 那句话里的下一步**真的能分辨**两种情形——在线跑一次会把"镜像没取过"与"上游丢了它"分开 |
