# 验收机制

> **这份文件是什么**：docs/development/README.md 原「验收机制」一节 —— 什么算做完、谁来核、核什么。
> **为什么单独成文**：这一节 39KB，与「怎么工作」不是同一件事：前者是每次交付要过的闸，后者是日常节奏。
> **这份文件里没有逐版表**（逐版账本见 [ledger.md](./ledger.md) / [stages.md](./stages.md)）。
