# v0.100 计划 — **层 1 的两笔看不见的账**

> 来源：一个很自然的问题——"如果我只用得到**最新版本**的代码，一个有很多提交的仓库
> 会不会白占我的磁盘？"
>
> 这个问题在 ngm 上格外值得回答，因为 ngm 的依赖**就是 Git 仓库**（[ADR-002](../adr/adr-002-git-direct.md)），
> 而它的本地根基是一个 `git clone --mirror` 的裸仓库（`internal/git/clone.go`）：
> **用户为整个历史付磁盘，是设计的结果，不是意外。**

---

## 1. 先取证（不猜）

三个读数，都在本机实测（2026-10-15）：

| 量 | 值 |
|----|----|
| `express` 的 mirror（`--mirror`，全部 refs） | **18.41 MiB**（in-pack 54155 个对象 / 3982 个 ref / 默认分支 6181 个提交） |
| 它最新一版的源码（HEAD 树） | **694.33 KiB** |
| 若每个提交各存一份完整快照 | 6181 × 694 KiB ≈ **4.1 GiB** |
| 实际 ÷ 朴素 | **约 228 倍压缩** |
| 其中**不在**默认分支历史上的对象 | **21610 / 54155（约 40%）** |
| `lodash` 的 `--depth=1` 克隆 | 5.36 MiB，其中 `.git` 只占 **0.82 MiB**，工作区 4.54 MiB |

⇒ **"提交多"几乎不是成本来源**。（这一条是本版最该被记住的结论：
18.41 MiB ÷ 694 KiB ≈ 26 倍才是"全历史 vs 最新版"的真实倍率。）

### 1.1 但取证里冒出来两笔"看不见的账"

**① 一次被中断的克隆会留下一个没有任何人认领的包。**

```
lodash-lodash-full.git   66.82 MiB / in-pack: 0 / packed-refs 不存在
```

**② git 自己不会及时收走它。** 实测 `git gc` 会删 `objects/pack/tmp_*`，
但**只删超过 14 天**的（13 天存活、15 天被清 ⇒ 阈值即 `gc.pruneExpire` 默认的 `2.weeks`）。

### 1.2 而文档把出路写在用户那一边

`docs/internals/metrics.md` 的"两层的分工"表：层 1 的回收是
"`git gc` —— git 的既有能力，**用户随时可跑**"。
而 v0.7 起 `store usage` 已经把层 2 的体积摆了出来 ⇒
**层 1 的体积成了一个"看得见却点不动"的位置**：用户拿到"这个 mirror 占了 18 MB"之后，
下一步只能自己去猜 `~/.ngm/mirror` 在哪、以及该跑什么。

## 2. 计划

| # | 项 | 验收 |
|---|----|------|
| 1 | **占用可见**：`ngm store usage` 增报层 1（逐仓库体积 / 其中多少是 packfile / 多少是残骸 / 点名 `NO REFS` 的目录） | 只读（V14 快照网）；小计与明细**逐项**相等；只有层 1 的机器不再被告知"没有可报告的东西"（这条提前返回是既有缺陷，随本版修掉） |
| 2 | **残骸可回收**：`ngm store prune` 增收 `objects/pack/tmp_*`（门槛 `MirrorResidueGrace` = 1 小时） | 牙齿：去掉年龄门槛 ⇒ "年轻的残骸必须留下"红；边界：对象库里除残骸以外的**每一个**文件都必须活下来；0 门槛被拒 |
| 3 | **历史可整理**：新增 `ngm store gc [--dry-run]` | `--dry-run` **0 个 git 子进程**（`git.SpawnCount` 仪器断言）；没有 ref 的目录与不是裸仓库的路径**跳过并点名**；整理之后 mirror **仍然解析得出那个 commit**；部分失败不伪装成成功（码 4）+ 已整理好的照常打印 |
| 4 | **ADR-030**：把"镜子仍是全量"写成**决定**（拒绝 `--single-branch` 与部分克隆） | 理由可核对：`refType` 允许 tag/branch（ADR-004）、digest 重放要读整棵树（ADR-008/010） |

## 3. 不做

- **不做** `--single-branch` / 部分克隆：见 [ADR-030](../adr/adr-030-mirror-reclaim.md) 的"决定"第 4 条；
- **不做**按可达性删除（两层都不做，[ADR-018](../adr/adr-018-store-reclaim.md) 的判定一位不动）；
- **不删**"一个 ref 都没有"的目录：它是一个目录，不是残骸文件。ngm 报出来 + 给出路
  （`rm -rf` + 重跑 `install`），不替用户删磁盘上不属于自己的东西；
- **不给** `store prune` 的层 1 段加 flag：门槛是**常量**（1 小时）而不是旋钮——
  `--older-than` 的既有语义（只对 `--orphans` 有效）是既有契约，本版一个字节没动它；
- **不做** `--json`：这一批输出的形状还没有被要求成机器可读（加它要连着 JSON 契约网一起动）。
