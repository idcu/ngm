# v0.45 计划 — 把 v0.43 的**公开跳过**归零

> 范围来源：v0.44 候选第 2 条（"参数维度两处遗留"里的**子命令层的 flag**）。
>
> 一句话目标：v0.43 那张布尔 flag 的网报出 **3 处公开跳过**。
> 这一版把这三处**一个个看过去**——该测的测掉，不该算在它头上的还回去，
> 并让"跳过"这个口子在结构上**归零**。

---

## 0. 起点：三处跳过分别是什么

| 跳过 | 初判 | 待验证 |
|------|------|--------|
| `store --dry-run` | 属于子命令 `store prune` | 真的是子命令层？ |
| `store --orphans` | 同上 | 同上 |
| `typecheck --minify` | 同上（v0.43 的注释这么写的） | **真的是吗？** |

## 1. 要做的三件事

1. **派生改成按 flagset 块**：`newFlagSet("name"` 到下一个声明之前，
   名字等于命令名的块归 v0.43，名字带空格的块（`store prune`）归新网。
2. **子命令层立同一套四断言**（`--flag` ≡ `--flag=true` · `=false` ≡ 不给 ·
   `=x` 必须失败 · `ZZ-JUNK` 必须被当成 positional 而不是被吞掉）——
   与 v0.43 **共用**同一个断言函数，两层不可能各自漂移。
3. **覆盖并集守卫**：两张网合起来的 (命令, flag) 集合必须覆盖**全部**派生出的布尔 flag；
   落不进集合的就是**没人看的东西**。

## 2. 验收

```bash
gofmt -l . && go vet ./... && go build ./...
go test -count=1 -run 'TestV43|TestV45' -v ./cmd/ngm     # 读数：跳过应为 0
go test -count=1 ./...                                   # 整套，不手挑
bash scripts/check-docs-links.sh
```

**牙齿**（至少两道）：

| 探针 | 期望 |
|------|------|
| 派生退回"只找 `<命令名>.go`" | 覆盖并集守卫红，点名那些没人看的 flag |
| 派生静默返回空 | v0.43 的规模守卫红（表不能自己空掉） |
