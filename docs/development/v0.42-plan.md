# v0.42 计划 — **取值 flag 的空值**

> 范围来源：[v0.41 复盘](./v0.41-retrospective.md) §7 候选 1。
>
> 一句话目标：v0.41 修了 `--dir=`（空串被静默当成 CWD）。这一版把同一条教训**推广到全部取值 flag**：
> `--engine=` / `--outfile=` / `--outdir=` / `--hook=` / `--loader=` / `--target=` / `--format=` /
> `--path=` / `--ref-type=` / `--runtime=`。

---

## 0. 判据：两条不变量

| # | 不变量 | 为什么 |
|---|--------|-------|
| 1 | **显式空值要么与"没给这个 flag"完全等价，要么失败**——绝不能"两个都成功、结果却不同" | "两个都成功却不同"**正是"静默改变行为"的定义**，也正是 v0.41 那个缺陷的形状 |
| 2 | **任何一次运行都不许在 CWD 里留下东西** | v0.41 的血：判据把 CWD 换成空目录，跑完检查它是否还是空的 |

判据刻意**不要求**"空值必须被拒绝"——**被明确拒绝**与**等价于不给**都是合格处置：
前者用户当场就知道，后者没有副作用。不合格的只有"静默地走了另一条路"。

## 1. 要测的 (命令, flag) 组合

| 命令 | flag |
|------|------|
| `add` | `--ref-type` · `--path` |
| `audit` | `--hook` |
| `build` | `--engine` · `--outfile` |
| `transform` | `--engine` · `--loader` · `--target` · `--format` · `--outfile` |
| `typedecl` | `--outdir` · `--engine` |
| `typecheck` · `css` | `--engine` |
| `init` | `--runtime` |

对照运行的办法：把那个 flag **从参数表里去掉**（`withoutFlag`），其余完全相同。

## 2. 纪律：探针先把 CWD 换掉

v0.41 的探针把**仓库**写脏了（`cmd/ngm/ngm.json` + `src/`）。
所以这一版的探针与网都**先把 CWD 换到一个临时目录**，并用"它是不是还是空的"当证据。
