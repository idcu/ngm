# v0.91 复盘 — **第二步做完：33 秒 → 1.33 秒；登记表只剩一条**

> 计划：[v0.91 计划](./v0.91-plan.md)
>
> 一句话结论：v0.90 把每条链接的 `cd … && pwd` 去掉了（133.72s → 33.07s），
> 但**每条链接仍然 fork 一次**（`$(normalize_path …)`）。这一版把规范化搬进 awk，
> 整条流水线只剩一个进程 ⇒ **1.33 s**（相对原实现 ≈100×）。
> 另外：登记表里最后一条可测的也进去了——而它当时写的理由是**错的**。

## 1. 数字

| 版本 | 那条检查的耗时（真实仓库，docs + README） |
|------|------------------------------------------|
| 直到 v0.89 | **133.72 s**（每条链接：`dirname` + `cd … && pwd` + 每文件 `sed`/`grep`） |
| v0.90 | **33.07 s**（纯 bash 规范化；但 `$(normalize_path …)` 仍每条链接 fork 一次） |
| **v0.91** | **1.33 s**（规范化搬进 awk；bash 只做 `[ -f ]` 这种内建） |

这条检查每次 CI 与每次全量测试都要跑一次，所以省下的是**每一次**。

## 2. 重写的凭据是"逐字对照"，不是"我觉得"

重写一个**会报错**的检查，最容易的失败方式是把它改得**不再报错**（然后一切看起来都全过）。
所以流程是：

1. 从 git 取出 v0.90 的实现；
2. 造一份 **20 例刁钻夹具**：反引号里的示例 · 一行两条链接 · `..` 退到根 · 根文件（base 为空）·
   `#锚点` · 外链 · 非 `.md` · label 里的括号 · target 里的括号 · 子目录 · `.txt` · `vendor/`；
3. 新旧各跑一遍，**逐字 diff**；
4. 只有 `IDENTICAL` 才继续。

**对照抓到我自己两处 bug**（都是"看起来等价"的那种）：

- `..` 退到根时我只用 `sub(/\/[^\/]*$/, "", out)`——`out` 里没有 `/` 时它**不匹配**，
  于是那个 `..` 变成空操作（`docs/development/../../docs/x` 被解析成 `docs/docs/x`）；
- base 为空时我拼出了**前导 `/`**（`"" + "/" + t`），相对链接因此变成绝对路径——
  根目录的 `README.md` 正好命中。

## 3. 把一次性的对照固化成常驻判据

`TestV91DocsLinksGoldenCases`：同一份夹具、逐条断言结论（`BROKEN LINK in <file>: <line>:<原文>`，
排序后整个集合相等；加计数行）。写它的时候正好又验证了一次：**我手写的期望行号是错的，
而两个实现一致**——出问题的是我的期望，不是实现。

其中一处**已知漏检**写进了判据注释而不是留给猜：`[x](./b(c).md)` 这种 target 里有 `)`
的链接，这条检查**看不见**（匹配只到第一个 `)` 为止）。新旧实现一致，属既有语义；
要改它得单独论证。

## 4. 登记表只剩一条——而它当时写的理由是错的

v0.89 给 `check-gitee-release-status.ps1` 写的理由是"该读数没有离线模式（无 `--api-base`）"。
v0.91 接它的时候看了一眼实现：**`GITEE_API_BASE` 一直在那里**（`scripts/check-gitee-release-status.sh`
第 39 行）。也就是说它一直可以对着假 API 跑——**那条理由是写下时没人验过的猜测**，
而接进判据花了两分钟。

`TestV91GiteeReadingRunsOffline` 用假 API 断言三种结论：附件齐 ⇒ exit 0 且报 `OK (7 attachments …)` ·
缺附件 ⇒ exit 1 且**点名**缺哪一个 · 请求失败 ⇒ exit 3 且 `NOT CHECKED`（查不动既不报缺、也不报成功）；
并顺带跑一遍 Windows 入口，要求同一份实现的同一个结论。

> 夹具也记一条：**假 API 要照着实现的判据造**。第一版没写 `id`，三条断言全错成
> `MISSING`——脚本的规则是"没有 `id` = 没有 release"。

`explainedNotAutomated` 现在 **1 条**：`upload-gitee-assets.ps1`（真需要凭据；
它做的事没有假 API 能替代）。
