# v0.82 计划 — **把上一版记下的六条欠账做掉**

> 来源：[v0.81 计划](./v0.81-plan.md) §3「已知未做（记下来，不假装查过）」。
>
> 一句话目标：v0.81 把新表面的 7 处洞补上了，但它在计划里**诚实登记**了六条没做的。
> 挂着不改的欠账与"我忘了它"在清单里长得一样——本版把它们做掉。

## 0. 起点

v0.81 §3 登记的六条：

1. 上游可控的 `subPath` 无校验（当前是**巧合性防护**，不是设计）
2. purl 类型与 percent-encoding 未核对
3. `spdxNamespace` 不哈希 digest
4. `--out` 非原子写、不校验目标是否在项目内
5. `attest` 两次读 lock（TOCTOU 面）
6. `json.MarshalIndent` 的 HTML 转义

### 1b. 过程中发现的（不在原六条里）

| 项 | 发现 |
|---|------|
| **`ngm.json` 与 `ngm.mappings.json` 写出后是 0600** | 三份 `writeFileAtomic` 里**只有 lock 那份**有 v0.66 加的 `Chmod(0644)`，另外两份没有。而这两个文件与 lock 一样是要提交进 Git、供团队共享的。**同一条缺陷在另外两个文件上还活着** —— 这是"规则写在第二个地方"的直接代价 |
| **`#path=..\..\x` 能通过校验** | addspec 那份只按 `/` 切分，反斜杠形态被当成一个普通段名。Windows 上 `\` 是分隔符 |
| `#path=/etc` 与 `--path=/etc` 处置不同 | 前者去斜杠后接受（`addspec_test` 的用例），后者拒绝（`error_surface_test` 的用例）。**两条都是既有决定**，不是缺陷——但一旦被人顺手统一，必须是有意识的决定 ⇒ 用判据钉住 |

## 2. 不做

- 不改 `#path=/etc` 与 `--path=/etc` 的不对称（两条都是现有测试钉住的决定，
  统一成哪一边都该是一次**有意识的**改动，本版只把它变成会红的判据）；
- 不给 `--out` 加"必须在项目目录内"的校验（用户显式给的路径，越界是他的选择；
  真正的风险是截断文件，已由原子写解决）；
- 不动 `purl` 的 type（`pkg:git/…`）——需先核对 purl-spec 的类型表，仍未实测，
  继续挂在"已知未做"里（见 §3）；
- 不新增契约网。

## 3. 仍然没做（继续诚实登记）

| 项 | 为什么 |
|---|--------|
| `--out` 目标是否在项目内 | 用户显式路径，风险有限 |
| `spdxNamespace` 用 `ngm.invalid` 域 | 是刻意的可复现占位（`attest` 同款）；是否该换成真实可解析域未决定 |

### ✅ 已核对并销账：`pkg:git/…` 的 purl type

计划 §2 曾把"purl type 的合规性"列为不做（未核对规范）。本版核对完毕：

- 来源：`purl-spec` 的 `purl-types-index.json` 与 git 类型的定义文档；
- `git` 是**已注册**的 purl type（与 `github` / `gitlab` / `bitbucket` / `generic` 并列）；
- 语法 `pkg:git/<namespace>/<name>@<version>?<qualifiers>#<subpath>`；
- namespace **必填** = 源码宿主；name **必填** = 仓库名（含 owner）；
- version 可选，定义原文"Ideally a commit or tag"——ngm 给的正是 **commit**；
- subpath 受支持（v0.82 起百分号编码）。

**唯一记录在案的歧义**：规范说 name 是"repository name with owner"（自身含 `/`），
而通用解析器按最后一段切分 name。于是 `pkg:git/github.com/org/repo@<commit>`
可能被读成 namespace=`github.com/org`、name=`repo`。**往返不受影响**
（namespace + "/" + name 恒等于 canonical），因此不改形状——
但把它写进 `TestV82PurlMatchesTheRegisteredGitType`，免得后来者以为是 bug。

> 这一条销账的意义：清单里"未核对"与"忘了"长得一样。
> 核对只花几分钟，换成一条钉住的判据，比一直挂着强。
