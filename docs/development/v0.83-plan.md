## 0. 先复核，再拍板（v0.80 有一句话是错的）

v0.80 写"地址校验刻意拒绝单标签主机名**与 IP 字面量**"。复核：

| 写法 | 实测 |
|------|------|
| `git://localhost/org/repo` | ✗ 拒（`unknown host "localhost"`） |
| `git://127.0.0.1/org/repo` | 主机通过——拒的是**路径段数**（我的 fixture 只写了一段，是我写错了） |
| `https://192.168.1.10/org/repo` | ✓ 允许（host 含点即可） |

即被拒的只有**单标签主机名**；IP 与内网域名一直能用。更正写在 v0.83 复盘 §0。

## 1. 计划

| # | 项 | 验收 |
|---|----|------|
| 1 | **ADR-029**：收下回环（只收 `localhost` / `127.0.0.1`） | 四种写法归一到同一 canonical；其余单标签主机名照旧拒绝；报错把三条出路说清 |
| 2 | 边界写进 ADR（不留着让人猜） | `[::1]` 不收 · 端口仍拒 · `git://` 协议仍拒 · `net:` 门禁不动 · 内网 IP 一直允许 |
| 3 | **修坏配置静默退化**：`newProjectEnv` 里 `config.Load` 的错误不再被吞 | 坏配置 ⇒ `ConfigInvalid`（exit 3）且用户看到的文本点名文件与字段；没有配置文件照常 |
| 4 | 判据 + 登记 | `internal/resolve` 的回环判据 · `cmd/ngm` 的坏配置判据（含"合法配置照常"的牙齿）· 两条登记 |

## 2. 不做

- 不为了让本机 `git://` daemon 可用而放开**协议**（`defaultProtocol ∈ {ssh, https}` 是有意的）；
- 不动 `net:` 门禁；不为测试造本地 TLS git 服务器。
