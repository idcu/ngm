# v0.59 计划 — **给"内部失败"一个自己的码（6）**

> 范围来源：v0.57 复盘候选 1（"码 1 兜着两类不同的事"）。
> 本版是这一系列**第一次动退出码契约**，按项目纪律**先立 ADR**。

---

## 0. 起点

v0.57 量出码 1 有五类来源，其中最后一类与策略无关：
**13+ 处"结论算出来了却说不出去"**（写 stdout / 编码 / 读 stdin 失败）＋ panic。

CI 无法区分"**上游漂了**"（1，要人看）与"**我写不出去**"（重跑可能就好）。

## 1. 决定（ADR-026）

- 新增 **`CodeInternal = 6`**，语义"内部失败"；
- 覆盖三类：panic · IO/编码/读取失败 · **够到 `errs.ExitCode` 兜底的、没走错误模型的错误**；
- 码 1 的四类策略来源**一个也不搬**；
- 每个命令的 usage 补上 `6  internal failure`（本项目约定：用法里写着它**实际**会退哪几个）。

## 2. 验收

```bash
go test -count=1 -run 'TestV21|TestV22|TestV24|TestV56|TestV57' -v ./cmd/ngm
go test -count=1 ./...          # 整套，不手挑
gofmt -l . && go vet ./... && bash scripts/check-docs-links.sh
```

**码 6 必须可测量**（V22 的规矩是"声明了就要能测"）：给 `dispatch` 传一个
**永远写失败的 writer**，命令算完结论、写报告时失败 ⇒ 退 6。

**牙齿**：① 把某处 `errs.CodeInternal.ExitCode()` 改回字面量 `return 1` ⇒ 判据要红
（只数"处数"是抓不到的——要**对账每一处退的是哪个码**）；② 从文档那一行里删掉类别 ⇒ 红。
