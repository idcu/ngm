# v0.16 计划 — 机器可读输出不能说谎

> 范围来源：[v0.15 复盘](./v0.15-retrospective.md) §7 候选 1（"示例命令能否跑通"）
> 的替代方向：那条线需要 fixture、引擎与网络，**网会变成联网测试**，与本项目
> "网必须确定性、离线"的纪律冲突。本版改为钉住**同一类契约里可判定的那一半**：
> `--json` 这份**给脚本读**的输出。

---

## 0. 为什么有这一版

7 个命令带 `--json`（verify / audit / tree / why / outdated / engines / integrations），
它们的报告是**给 CI 读的**。而这份契约此前只有零散覆盖：

| 既有覆盖 | 断言到什么程度 |
|---------|--------------|
| `acceptance_m5_test.go` | 某个场景里 `Summary.ExitCode == 0` |
| `supplychain_acceptance_test.go` | **只查 `exitCode` 键存在** |
| `integrations_acceptance_test.go` | 成功场景里 `ExitCode == 0` |

**没有任何一条把"报告里写的退出码"与"进程真实的退出码"绑在一起**，也没有一条
在**失败态**上检查 stdout 的形状。三处 payload 都带 `exitCode` 字段——它们是脚本的判据。

还有一处更基础的缺口：**这 7 个命令的 JSON 顶层形状，用户侧一个字都没有**
（`engines list` 返回数组这件事只写在代码注释里）。

---

## 1. 网：`TestV16JSONReportsTellTheTruth`

**20 个状态**（17 次"带 `--json` 与不带"的对照 + 3 条输入错误路径），每次调用核对四条：

| # | 规矩 | 为什么 |
|---|------|--------|
| ① | stdout 要么为空、要么是**恰好一份**合法 JSON 文档 | 半份文档会让 `jq` 直接失败，而 CI 看到的是一个"有输出但解析不了"的谜 |
| ② | **`--json` 不改变退出码** | 同一状态两种模式退不同的码，等于让"是否加 `--json`"改变判定 |
| ③ | 报告里的 `exitCode` / `summary.exitCode` **等于进程退出码** | 机器可读输出不许说谎——这是本版的核心 |
| ④ | **输入错误时 stdout 为空**，而**失败态不是输入错误**（`verify` 的失败态**就是**一份报告） | 两条都是给脚本的：前者说"我没有报告可给"，后者说"报告在此，结论是它" |

状态序列**刻意排序**（干净 → 漂移 → 篡改）：后两种状态会互相掩盖，
先篡改会让之后每个 `verify` 都退 2、漂移语义再也测不出来（探针踩过一次）。

`audit` 用本地 OSV 替身（`NGM_OSV_URL` + `grantNetFor`）覆盖两条路：
无漏洞（0）与发现 HIGH（1）——它是唯一"报告内容改变退出码"的命令，也是 ③ 最容易失守的地方。

## 2. 文档：把机器接口写给人看

`docs/guides/cli.md` 新增 **`--json` 的形状（机器接口）** 一节：**实测**的顶层形状表
（哪三个命令带退出码字段、哪两个命令返回数组），加那四条规矩。

**只记录，不统一**：`engines` 返回数组、其余返回对象，这是当前接口的一部分；
统一形状是破坏性变更，要另立决定，不在文档里顺手改。

---

## 3. 明确不做

| 不做的 | 理由 |
|--------|------|
| 逐条执行 `quickstart.md` 的示例 | 它的示例用真实 GitHub 仓库与真实引擎（`github:vuejs/core@v3.5.0`、`build --engine=esbuild`），网会变成联网测试 |
| 统一 7 个命令的 JSON 顶层形状 | 破坏性变更，需另立决定 |
| 给 `--json` 加 schema 校验（字段类型/必填） | 会与"只钉可判定的一半"冲突：字段类型是**演进中**的，钉死会让每加一个字段都要改网 |

## 4. 验收

```bash
go build ./... && go vet ./... && gofmt -l .
go test -count=1 -run 'TestV16' -v ./cmd/ngm
go test -count=1 ./internal/... && go test -count=1 -timeout 40m ./cmd/ngm
bash scripts/check-docs-links.sh
go test -count=1 -run 'TestDocsAnchorsResolve' -v ./cmd/ngm
```

牙齿：把 `internal/verify/report.go` 里 `s.ExitCode = r.ExitCode()` 改成常量，
网必须红（实测：三条状态断言同时报"该退 1/2 却退了 0"）。
