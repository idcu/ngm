# v0.52 复盘 — **把"刻意不修的"与"挂着的"变成具名的、可数的**

> 体例同各版：逐组验收 → 未达成项 → 设计偏离 → 缺陷清单 → 过程洞察 → 指标 → 下一版候选。
>
> 一句话结论：这一版没有动产品代码——它动的是**判据自己的账本**。
> 两处空洞形态相同：**"我知道它在那儿"与"我漏了它"，在源码/候选表里长得一样**。
> 一处收进静态普查的具名允许数，一处收进一张**必须写代价与挂了几版**的登记表。

## 1. 逐组验收

### 1.1 `duration.go` 的"故意"进登记 ✅

v0.49 的静态普查原本只看 `validate.go`。这一版加上第二个文件，
并给它一个**具名允许数**：

```
duration.go 有 10 处不带建议的裸错误，而登记的允许数是 9 ——
新增的解析错误要么自己带上建议，要么把这个允许数改大并在注释里写清为什么
```

为什么它值得登记：那是 ISO 8601 时长的**解析器**，它的错误只说"输入的哪一段看不懂"；
补"该怎么改"的职责在**字段层**（`minimumReleaseAge` 分支）——**一处代替十处**，
而且字段层知道这个值该填在哪个键里（v0.49 的决定）。

**没有这条登记，"故意不修"与"漏了"在源码里长得一模一样。**

读数：`config validation: 0 bare error(s) (exemptions 1, all present), 5 %w wrapper(s)`。

> 允许数是**实测的 10**。我第一版凭印象写了 8——写完立刻去数，改回实测值。
> v0.43 的那条教训（"守卫阈值是我拍的"）差一点又重演：**先量，再写数字。**

### 1.2 "挂着的"登记表 ✅

`TestV52TheDeferredListIsNamedAndCounted` 里的 `debts` 表，每条四个字段：
`what`（是什么）· `kind`（哪种）· `cost`（**做掉它要花什么**）· `since`（**从哪一版起挂**）。

读数：`deferred registry: 8/8 entries — map[已暂缓:1 故意:2 未做:4 未立纪律:1]`

| 种类 | 含义 |
|------|------|
| **故意** | 已决定不做，并写清了理由（不是忘了） |
| **未做** | 值得做、也做得动，只是还没做 |
| **未立纪律** | 还只是一句口号，没有机械判据钉住它 |
| **已暂缓** | **由人决定**先不做（不是我们判断的） |

### 1.3 牙齿 ✅（三道）

| 探针 | 结果 |
|------|------|
| 棘轮从 8 收紧到 7 | 红：`这张表有 8 条，而棘轮是 7——变多之前先想清楚` |
| 某条不写代价 | 红：`第 4 条（…）没有写**代价**——没有代价的登记，与'我忘了它'没有区别` |
| `duration.go` 的允许数改成 9 | 红：`有 10 处…而登记的允许数是 9` |

## 5. 过程洞察

### 5.1 "故意"必须写下来——否则它与"漏了"同形

源码里一处不带建议的错误，看不出作者是"想过并决定不做"还是"忘了"。
允许数把这件事变成**可数的**：超了就是新增的漏网，少了就提示收紧。

### 5.2 登记表：格式由机器守，内容由人写

判据能守的是：每条有代价、有版本、种类合法、总数不涨。
判据守不住的是：**代价写得对不对、值不值得做**——那需要人。
把这两者分开，是这张表能长期存在的前提（不然它会变成一份没人敢动的文档）。

### 5.3 这一版是"关于判据自己的"——而它的必要性是被上一版证明的

v0.51 刚刚演示了代价：同一条"归一化清单"在候选表里挂了**四版**，
真做掉它花了一个 25 行的助手加四行迁移。

> **没有证据与没有缺陷，在候选表里长得一样。**
> 这一版做的事情，就是让"没有证据"那一类**有名字、有代价、有年龄**。
