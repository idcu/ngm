# v0.49 计划 — **"注释比实现说得多"那一族的收口**

> 范围来源：v0.48 复盘候选第 1 条（也是那一版 §三·根因 1 的推广）。
>
> 一句话目标：`internal/config` 的 30 处校验全是裸错误（没有建议），
> 而包顶注释写着"返回的错误是给用户看的：包含字段路径与可操作 hint"。
> 这一版把这一族补齐，并留一条**静态**判据钉住它。

---

## 0. 起点：先量

| 项 | 数 |
|----|----|
| `internal/config/validate.go` 的裸错误 | **30**（含 5 处 `%w` 包装） |
| 带建议的 | **1**（v0.48 修的 `validateDepPath`） |

## 1. 判据

1. **字段级建议**：每个校验点用 `fieldErr(msg, hint)`——
   消息说哪里不对，建议说**该改成什么**。
2. **兜底不再遮蔽**：`errs.WrapUnlessHinted`（内层有建议时不附加兜底），
   三处调用点（`io.go` 加载器 · `config validate` 命令 · `add.go`）统一。
3. **静态普查**（新网）：`validate.go` 里
   - `errors.New(` 只允许出现在**例外表**里（每条写清为什么）；
   - `fmt.Errorf(` 只允许出现在**带 `%w` 的包装**里（它把内层的建议带上来）；
   - 例外表的键必须**仍然存在**（名单自己要有牙齿）。
4. **动态面**：三条校验类变体进错误面（`refType` 非法 · `vendor.mode` 非法 ·
   `minimumReleaseAge` 不是时长），并登记"建议必须承认这条形状"。

## 2. 验收

```bash
gofmt -l . && go vet ./... && go build ./...
go test -count=1 -run 'TestV31|TestV49' -v ./cmd/ngm
go test -count=1 ./...          # 整套，不手挑
bash scripts/check-docs-links.sh
```

**牙齿**：① 某处退回裸错误 ⇒ 静态普查红；② 兜底改回 `Wrap` ⇒ 动态面红。
