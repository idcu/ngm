# v0.71 计划 — **让 ADR 索引不再靠手抄（机械判据）**

> 范围来源：[v0.70 复盘](./v0.70-retrospective.md) §7 候选 1（"本次教训的兑现"）+ 候选 3。
>
> 一句话目标：**v0.70 修掉的那处"索引挂了数版没人红"，从此有东西会红。**

---

## 0. 起点

v0.70 修 ADR-027 索引行时发现：`docs/adr/README.md` 的索引里 ADR-025 的行**整行缺失**、
ADR-024 **重复两行**、ADR-026 的行与前者**粘连**——挂了数版没有任何判据变红。
根因与 v0.64 的 `schemaFiles` 同类：**清单活在人的脑子里，必然漂移**。

## 1. 处置

| 项 | 决定 |
|----|------|
| 新判据 | `TestV71AdrIndexCoversEveryAdrFile`（cmd/ngm，与其它文档判据同住） |
| 文件集 | `docs/adr/adr-*.md`（`os.ReadDir` 派生，不手写） |
| 索引行 | `docs/adr/README.md` 的表格（`readDoc`） |
| 检查 ① | 每个 ADR 文件**恰好一行**（缺失 = 漏登记；≥2 = v0.70 修掉的那类重复） |
| 检查 ② | 每行的链接必须指向真实存在的文件 |
| 检查 ③ | 每行必须恰好 3 列（4 个竖线）——"两行粘成一格"最先坏的就是列数 |
| 检查 ④ | 编号连续（001..N）：纪律是"被取代也不删除"，缺口只该来自文件丢失 |
| 登记 | `net_coverage_sources_test.go` 照例登记（what / why / source） |
| 附带 | ADR-027 §2 补一段 CI 消费路径（候选 3：生成 → cosign 签 → 消费方 verify） |

## 2. 验收

```bash
go test -count=1 -run 'TestV71AdrIndex' -v ./cmd/ngm
```

**牙齿**（实测记录在复盘）：把 ADR-027 的行复制一份 ⇒ 判据红，消息点名
`adr-027-attestation.md 在索引里出现了 2 次`；恢复 ⇒ 绿。

## 3. 流程纪律（本版起）

**交付即提交、提交即打 tag**（v0.70 补记提交的教训）：本版在一个提交里完成，
tag 打在该提交上，不再积批。
