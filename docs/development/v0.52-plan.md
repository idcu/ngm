# v0.52 计划 — **把"刻意不修的"与"挂着的"变成具名的、可数的**

> 范围来源：v0.49 候选 1（"故意不修"要立判据）+ v0.44 起一路挂着的"未证明/未处理"。
>
> 一句话目标：这一系列反复用过的招（负例名单 v0.15 · 缺口名单 v0.22 ·
> 退 0 登记 v0.37 · JSON 不适用登记 v0.50）——**契约看不见的地方必须具名**——
> 这次用在两处：**源码里的"故意"** 与 **候选表里的"挂着"**。

---

## 0. 起点：两个形态相同的空洞

1. `internal/config/duration.go` 的十处裸错误是**故意**的（字段层补建议更贴切）——
   但它在源码里与"漏了"长得一样。
2. 候选表里挂着若干"未做/未立纪律"——而 v0.51 刚刚演示了代价：
   同一条"归一化清单"挂了**四版**，真做的时候成本是一个 25 行的助手 + 四行迁移。

## 1. 判据

1. **v0.49 的静态普查扩到第二个文件**：`duration.go` 的裸错误处数有**具名允许数**
   （实测值，不是估的），超过即红；低于则提示可以收紧。
2. **一张"挂着的"登记表**（`TestV52…`）：
   - 每条必须有 `what` / `kind` / `cost` / `since`；
   - `kind` ∈ {故意 · 未做 · 未立纪律 · 已暂缓}，其中"已暂缓"是**人的决定**；
   - **总数是棘轮**（只许变少或持平）。

## 2. 验收

```bash
gofmt -l . && go vet ./... && go build ./...
go test -count=1 -run 'TestV49|TestV52' -v ./cmd/ngm
go test -count=1 ./...          # 整套，不手挑
bash scripts/check-docs-links.sh
```

**牙齿**：① 棘轮收紧 ⇒ 红；② 某条不写代价 ⇒ 红；③ `duration.go` 的允许数调小 ⇒ 红。
